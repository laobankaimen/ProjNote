# ProjNote 前端设计约定

面向独立项目负责人，信息以「项目 → 待办 → 现场事实 → 可追溯结论」组织。工作台是办公工具，默认显示真实空库，不用示例数字掩盖空态。

## Token

- 导航墨蓝 `#233348`；正文 `#24334A`；操作蓝 `#2465CE`。
- 工作台底色 `#F3F6FA`；纸面 `#FFFFFF`；边线 `#DFE5EE`。
- 状态用蓝、绿、赭红辅以中文文字，颜色不单独传达含义。
- 离线字体：`"Noto Sans CJK SC", "Microsoft YaHei", "PingFang SC", sans-serif`。正文 14px，标题 25px，辅助信息 12px；数据使用等宽数字，不加载外部字体。
- 间距以 4px 为基准；表格、筛选器紧凑，长文本行宽不超过 76 字符。

## 布局

左侧固定 210px 导航，顶部 72px 全局操作，正文左对齐。小屏导航折为横向滚动，双栏归为单栏。记录按真实时间串在一根细线上，作为产品最鲜明的辨识点；其余内容使用安静的表格、分组和留白。

```text
┌ 导航 ──┬ 工作区名称                搜索 / 速记 ┐
│ 今日   │ 标题 + 日期                  主操作 │
│ 项目   │ ┌ 待办工作 ──────┬ 今日记录时间线 ┐ │
│ 任务   │ │ 项目、状态、到期 │ 时间、事实、图片 │ │
│ 记录   │ └─────────────┴─────────────┘ │
│ 日志   │                                     │
│ 问题   │                                     │
└ 设置 ──┴─────────────────────────────────────┘
```

## 设计自评与约束

避免把所有数据切成同样的卡片；将统计收敛为工作台顶部一行事实，主要空间交给待办与记录时间线。现场记录用时间轴是来自记录工作本身的结构，并非装饰编号。模态框支持原生 dialog 焦点管理、Esc 和返回焦点，所有输入具名，键盘焦点可见；错误说明来自真实 API，保存中禁重复提交。初始空态直接给出新建项目、速记、显式加载示例的入口。没有假按钮、外网依赖或本地假数据。

构建后检查响应布局、空态、保存错误和终态编辑限制；动态路由采用 hash，满足单文件服务回退的部署条件。

## v0.3 首个增量

延续原有色板与紧凑表格。选中项目时展示服务端完整 DFS 任务树，折叠只影响可见行；筛选保留祖先并标注路径。全部项目显示分页平铺列表，避免给不完整分支伪造树形。行内编辑使用持续可见的小笔按钮，提供键盘入口；拖动仅由独立握柄启动，仍通过明确位置对话框确认。

操作历史收在详情的可展开区域，用本地时间、操作人和字段前后值展示事实。提醒以安静的到期列表出现，完成须服务端确认；不引入浏览器系统通知。工时以整数分钟为唯一来源，用日、项目、任务三种聚合说明投入，超过 8 小时是核对提示，24 小时是服务端硬约束；不把日志文字或预计工时加进实际工时。

行内编辑与新增表单延续按数据集和标签页隔离的草稿策略，API 409 展示对比并保留本地内容。提醒时间统一使用本机时区输入、RFC3339 传输。此增量不宣称完整 P0 或 GJB 合规，模板与标准证据仍待核对。

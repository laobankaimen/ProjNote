## 运行

构建产物位于 `dist/ProjNote`（Linux x64）和 `dist/ProjNote.exe`（Windows x64）。双击 Windows 程序会打开浏览器，也可以在终端启动：

```bash
./dist/ProjNote
# 明确指定便携数据目录
./dist/ProjNote --data-dir ./data
# 后台测试或手动打开浏览器
./dist/ProjNote --data-dir ./data --no-browser --port 18600
```

默认数据目录为可执行程序同级的 `data`，该位置不可写时使用用户配置目录。服务只监听 `127.0.0.1`，首选 18600，冲突后最多顺延 99 个端口。启动输出和数据目录中的 `runtime.json` 提供实际地址。初次打开为空工作空间；可以创建真实项目，也可在“设置与备份”显式导入示例数据。示例只允许写入空库。

关闭浏览器后服务继续运行。使用设置页“退出服务”、终端 `Ctrl+C`，或以下命令结束：

```bash
./dist/ProjNote --data-dir ./data --stop
```

`Alt+N` 速记、`Ctrl+K` 搜索仅在应用网页获得焦点时生效。速记可先不选项目；`#标签` 和能唯一匹配的 `@项目名` 会被识别。提醒时间语法尚未实现。图片支持 PNG/JPEG/GIF，单张不超过 20 MB/4000 万像素，单条最多 9 张；原字节保留，另生成缩略图。

任务有子任务时，进度/状态由子任务汇总；逾期是独立标记。问题按“新建→分析中→处理中→待验证→关闭”流转，关闭必须有原因、纠正措施和验证结果。已完成任务、已结束问题和归档项目在首版中只读，重开与版本修订后续补齐。

## 备份与恢复

设置页可以创建、下载完整 ZIP。程序启动及持续运行期间按日检查自动备份，每个包包含一致数据库快照、完整附件/模板和逐文件 SHA-256 清单，独立可恢复。目前保留全部备份；可以把下载的完整包存到另一介质。

恢复会替换当前业务数据，先退出同一数据目录的服务。CLI 会先校验路径、清单、文件哈希、SQLite 完整性/外键/版本、审计链和记录引用的原图；有现存数据库时先生成完整回滚包。

```bash
# 只校验，不覆盖数据
./dist/ProjNote --verify-backup /path/to/backup.zip
# 退出后恢复
./dist/ProjNote --data-dir ./data --stop
./dist/ProjNote --data-dir ./data --restore /path/to/backup.zip
./dist/ProjNote --data-dir ./data
```

如果原数据库已经损坏而无法生成回滚点，程序保留原目录并停止恢复。把损坏目录另存后，可使用一个新的空数据目录恢复备份。运行中不要只复制 `app.db`；先退出服务整体复制数据目录，或使用完整备份。

## 开发与验证

当前可复现基线：Go 1.24.0、Node 24、Vue 3.5.44、TypeScript 5.9.3、Vite 7.3.7；依赖精确版本以两个锁文件为准。这里是已验证开发环境，正式发布的工具链与目标平台兼容性另行验收。

```bash
make web                 # npm ci、类型检查、构建并复制内嵌资源
make build               # Linux/当前平台，无 CGO
make windows             # Windows x64 交叉编译
make test                # Go tests + vet
python3 scripts/smoke.py ./dist/ProjNote
```

已有依赖缓存的断网开发环境可使用 `make web NPM_FLAGS=--offline`。编译 Go 时需要 `internal/webui/dist`；仓库保留构建后的前端资源，修改前端后重新执行 `make web`。`make GO=/absolute/path/to/go build` 可指定工具链。

冒烟脚本只在系统临时目录创建数据，启动本地临时端口，检查端口顺延、单实例、真实 API、图片原字节、问题关闭、日志、搜索、备份校验和离线恢复。

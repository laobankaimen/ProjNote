## 运行

构建产物位于 `dist/ProjNote`（Linux x64）和 `dist/ProjNote.exe`（Windows x64）。双击 Windows 程序会打开浏览器，也可以在终端启动：

```bash
./dist/ProjNote
# 明确指定便携数据目录
./dist/ProjNote --data-dir ./data
# 后台测试或手动打开浏览器
./dist/ProjNote --data-dir ./data --no-browser --port 18600
```

默认数据目录为可执行程序同级的 `data`，该位置不可写时使用用户配置目录。服务只监听 `127.0.0.1`，首选 18600，冲突后最多顺延 99 个端口。启动输出和数据目录中的 `runtime.json` 提供实际地址。初次打开为空工作空间；可以创建真实项目，也可在“设置与备份”显式导入示例数据。示例只允许写入空库。

关闭浏览器后服务继续运行。使用设置页“退出服务”、终端 `Ctrl+C`，或以下命令结束：

```bash
./dist/ProjNote --data-dir ./data --stop
```

`Alt+N` 速记、`Ctrl+K` 搜索仅在应用网页获得焦点时生效。速记可先不选项目；`#标签` 和能唯一匹配的 `@项目名` 会被识别。新建速记可用 `!今天`、`!明天`、`!周五`、`!2026-11-10`，可附 `HH:mm`；也可显式选择提醒时间。未写时刻默认本地 09:00；今天已过时安排一分钟后。正文原样保留，无法解析时给出提示。提醒为一次任务，在应用中查看和完成；重复规则与系统通知尚未实现。图片支持 PNG/JPEG/GIF，单张不超过 20 MB/4000 万像素，单条最多 9 张；原字节保留，另生成缩略图。

任务有子任务时，进度/状态由子任务汇总；逾期是独立标记。问题按“新建→分析中→处理中→待验证→关闭”流转，关闭必须有原因、纠正措施和验证结果。已完成叶子任务可填写原因重开为进行中，父任务随之重算。已结束问题和归档项目仍只读，文档版本修订后续补齐。

选择项目时显示完整任务树，可折叠或保留筛选项的祖先路径；全部项目仍分页。名称、负责人、截止日期可行内编辑，叶子任务另可编辑进度和状态，Enter/失焦保存、Esc取消。任务支持拖到参照行上/中/下方后确认位置，也可使用“移动”按钮选择位置；批量修改失败时整批回滚。记录支持未归类筛选、批量归类、标签筛选和图片左右切换/缩放。

编辑草稿按数据集隔离存到本浏览器，重新打开时可选择恢复；草稿尚未写入数据库，不能替代备份。旧版本内容冲突时显示字段比较，不自动覆盖数据库新内容。回收站只提供恢复，不提供永久删除；非空项目、归档内容及已结束的问题不能回收，任务子树的完整版本确认由API支持，界面暂仅回收叶子任务。

实际工时在“工时”页独立录入，精确到分钟，可关联项目或叶子任务。按日、周和日期范围查看项目/任务汇总；超过 8 小时提示核对，同一天全部项目合计不能超过 24 小时。日/周日志只引用这些条目，人工修改日志文字不会改变工时。各类详情可查看操作前后快照和历史。

## 备份与恢复

设置页可以创建、下载完整 ZIP。程序启动及持续运行期间按日检查自动备份，每个包包含一致数据库快照、完整附件/模板和逐文件 SHA-256 清单，独立可恢复。默认保留最近 30 个普通备份，可在设置中调整为 2～365 份和容量预算。只有新包完整校验通过才清理旧普通包，最新有效包和受保护的升级/恢复/迁移回滚点始终保留。设置页显示最近成功、失败原因与磁盘空间；可以把下载的完整包存到另一介质。

恢复会替换当前业务数据，先退出同一数据目录的服务。CLI 会先校验路径、清单、文件哈希、SQLite 完整性/外键/版本、审计链和记录引用的原图；有现存数据库时先生成完整回滚包。

```bash
# 只校验，不覆盖数据
./dist/ProjNote --verify-backup /path/to/backup.zip
# 退出后恢复
./dist/ProjNote --data-dir ./data --stop
./dist/ProjNote --data-dir ./data --restore /path/to/backup.zip
./dist/ProjNote --data-dir ./data
```

如果原数据库已经损坏而无法生成回滚点，程序保留原目录并停止恢复。把损坏目录另存后，可使用一个新的空数据目录恢复备份。运行中不要只复制 `app.db`；先退出服务整体复制数据目录，或使用完整备份。

设置页的“迁移与恢复向导”可校验输入并生成按平台引用路径的维护指令；Windows 指令使用 PowerShell。网页不直接替换运行中的数据库。迁移到一个新的空目录时，先停服：

```bash
./dist/ProjNote --data-dir /path/to/current --stop
./dist/ProjNote --data-dir /path/to/current --relocate /path/to/new-empty-directory
./dist/ProjNote --data-dir /path/to/new-empty-directory
```

迁移后原目录完整保留，新目录包含当前数据库、附件/模板及本次受保护迁移快照；旧备份历史继续保存在原目录。以后从新目录启动，或把该命令保存成快捷方式。新旧目录不能相同、互相包含或覆盖非空目录。

v0.3 读取 schema1/2 数据库时，会先创建并验证受保护的完整旧版快照，再事务迁移到 schema3。可恢复 schema1/2/3 的完整包；旧版不能读取较新的数据库，降级使用对应的升级前快照。

## 开发与验证

当前可复现基线：Go 1.24.0、Node 24、Vue 3.5.44、TypeScript 5.9.3、Vite 7.3.7；依赖精确版本以两个锁文件为准。这里是已验证开发环境，正式发布的工具链与目标平台兼容性另行验收。

```bash
make web                 # npm ci、类型检查、构建并复制内嵌资源
make build               # Linux/当前平台，无 CGO
make windows             # Windows x64 交叉编译
make test                # Go tests + vet
npm --prefix web run test:drafts  # 草稿并发与数据集隔离
python3 scripts/smoke.py ./dist/ProjNote
python3 scripts/smoke_v02.py ./dist/ProjNote
python3 scripts/smoke_v03.py ./dist/ProjNote
# 可选：保留旧程序时验证真实升级
python3 scripts/smoke_upgrade.py /path/to/ProjNote-v0.2 ./dist/ProjNote --legacy-schema 2 --legacy-version 0.2
```

已有依赖缓存的断网开发环境可使用 `make web NPM_FLAGS=--offline`。编译 Go 时需要 `internal/webui/dist`；仓库保留构建后的前端资源，修改前端后重新执行 `make web`。`make GO=/absolute/path/to/go build` 可指定工具链。

冒烟脚本只在系统临时目录创建数据，启动本地临时端口，检查端口顺延、单实例、真实 API、图片原字节、问题关闭、日志、搜索、备份校验和离线恢复。
